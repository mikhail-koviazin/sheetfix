sheetfix

Photos in an Excel file are invisible when it is opened in WeChat on an iPhone. Drop the file here to get a fixed copy.

Drop an .xlsx file

or click to choose one

Nothing is uploaded. The file is opened, repaired and saved by this page inside your browser. There is no server behind it, no account and no storage: close the tab and nothing of it remains.

A picture in an .xlsx file carries its position twice: anchored to a cell, and as absolute coordinates. Excel reads the anchor and ignores the rest, so on a computer the file always looks right. WeChat on iOS reads only the absolute coordinates, which Excel does not always keep up to date and some tools never write at all. Then the pictures land far below the table, or are not drawn. This page recomputes the absolute coordinates from the anchors. Excel does not read them, so the fixed file stays identical everywhere else.
